# Changelog

## 0.4.0 — 2026-11-02

Поиск времени по описанию: HTTP LLM-адаптер со strict JSON Schema, серверная проверка
диапазона, реальные слоты PostgreSQL и диалог с отдельным подтверждением записи.
Суточный бюджет в PostgreSQL, IP-лимит Redis, таймаут и переход к календарю при отказе.
25 contract-fixtures и live-eval runner; реальный провайдер и его качество пока не проверены.

## 0.3.0 — 2026-11-01

Транзакционные события записи/отмены, RabbitMQ/Celery, HTTP-провайдер уведомлений,
повторы и статусы доставки. Локальный провайдер принимает сообщения без отправки писем.

## 0.2.0 — 2026-11-01

Общие атомарные лимиты входа и записи через Redis, JSON 429/Retry-After,
явный отказ записи при недоступности лимитера. Redis включён в Compose и CI.

## 0.1.0 — 2026-10-30

Первый MVP SlotBook:

- Публичная страница специалиста, календарь и запись на 30 минут.
- Секретная ссылка для просмотра и отмены записи до её начала.
- Вход специалиста, список записей и управление расписанием.
- Защита от пересечений и двойной записи в PostgreSQL; сессии, CSRF и проверка владельца.
- Docker Compose, Nginx, проверка готовности БД и миграций, GitHub Actions.
- Синтетическое демо, разбор кода и инструкции запуска и восстановления БД.

Email-уведомления, регистрация, восстановление пароля и AI-подбор времени отсутствуют.
Публичный хостинг не входит в комплект; для него требуется отдельный HTTPS-сервер.
